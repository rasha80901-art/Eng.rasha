# النسخة النهائية — محاكاة تصيّد توعوية

هذه نسخة متكاملة وجاهزة للنشر، مصممة للاستخدام الداخلي المصرّح به فقط.

## المكونات
- `index.html` : صفحة الحملة التسويقية الوهمية
- `awareness.html` : شاشة التحذير الحمراء ثم كشف المحاكاة والدورة القصيرة
- `admin.html` : لوحة نتائج المشرف + تصدير CSV
- `styles.css` : كامل التصميم
- `config.js` : إعدادات Supabase
- `supabase.sql` : الجداول والدوال والسياسات
- `netlify.toml` : إعدادات بسيطة للنشر على Netlify

## المزايا
- تصميم جذاب يشبه حملات الجوائز
- اسم عام غير تابع لشركة حقيقية: **مزايا الاتصالات**
- شاشة تحذير حمراء مع خطوط نقل بيانات متحركة
- اختبار قصير بعد كشف المحاكاة
- لوحة إدارة للمشرف
- تصدير النتائج CSV
- تسجيل:
  - هل ضغط المشارك
  - هل أكمل التوعية
  - الوقت
- لا يتم جمع:
  - كلمات مرور
  - رموز OTP
  - بيانات بنكية
  - بيانات دخول حقيقية

## خطوة 1: إنشاء مشروع Supabase
1. افتحي Supabase
2. أنشئي مشروعًا جديدًا
3. من **SQL Editor** شغّلي ملف `supabase.sql`

## خطوة 2: إنشاء حساب المشرف
1. من **Authentication > Users**
2. أنشئي مستخدمًا جديدًا ببريدك وكلمة مرور
3. انسخي `UUID` الخاص بالمستخدم
4. شغّلي هذا الأمر في SQL:
```sql
insert into public.simulation_admins(user_id)
values ('PUT_ADMIN_USER_UUID_HERE');
```

## خطوة 3: إضافة المشاركين
مثال:
```sql
insert into public.simulation_participants(display_name) values
('أحمد'),
('سارة'),
('محمد'),
('نورة');
```

## خطوة 4: ربط الموقع بـ Supabase
من **Settings > API** انسخي:
- Project URL
- anon public key

وضعيهما في `config.js`

## خطوة 5: رفع المشروع على Netlify
ارفعي جميع الملفات كما هي.
بعد النشر سيظهر لك رابط مثل:
`https://your-site.netlify.app`

## خطوة 6: استخراج روابط المشاركين
بعد رفع الموقع، افتحي SQL وشغّلي:
```sql
select
  display_name,
  participant_token,
  'https://YOUR-SITE.netlify.app/?t=' || participant_token as campaign_link
from public.simulation_participants
order by created_at;
```

## خطوة 7: الدخول إلى لوحة المشرف
افتحي:
`https://YOUR-SITE.netlify.app/admin.html`

ثم سجّلي الدخول ببريد المشرف وكلمة مروره.
